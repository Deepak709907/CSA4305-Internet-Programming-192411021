Question 5: PHP Validation

Pseudocode for validating user input in a web form using PHP: check for empty fields, validate the email format and password length, and only allow submission once all validations pass.

Code

<?php
$name = "Ram";
$email = "Ram@gmail.com";
$password = "Pass1234";
$errors = [];

if (empty($name))
    $errors[] = "Name is required";

if (!filter_var($email, FILTER_VALIDATE_EMAIL))
    $errors[] = "Invalid email";

if (strlen($password) < 6)
    $errors[] = "Password must contain at least 6 characters";

if (empty($errors)) {
    echo "Validation Successful<br>";
    echo "Form submitted successfully";
} else {
    echo "Validation Failed<br>";
    foreach ($errors as $error)
        echo $error . "<br>";
}
?>
