Question 2: MVC Workflow

Pseudocode representation of the Model–View–Controller workflow: the Controller receives the request, the Model supplies the data, and the View renders the response.

Code

public class Main {

    // Model
    static class StudentModel {
        String getStudentName() {
            return "Ram";
        }
    }

    // View
    static class StudentView {
        void display(String name) {
            System.out.println("Student Details");
            System.out.println("Name: " + name);
        }
    }

    // Controller
    static class StudentController {
        StudentModel model;
        StudentView view;

        StudentController(StudentModel model, StudentView view) {
            this.model = model;
            this.view = view;
        }

        void processRequest() {
            System.out.println("Request received by Controller");
            String name = model.getStudentName();
            System.out.println("Model processed the request");
            view.display(name);
            System.out.println("Response sent to User");
        }
    }

    public static void main(String[] args) {
        StudentModel model = new StudentModel();
        StudentView view = new StudentView();
        StudentController controller =
            new StudentController(model, view);

        controller.processRequest();
    }
}

Output

Request received by Controller Model processed the request Student Details Name: Ram Response sent to User === Code Execution Successful ===
