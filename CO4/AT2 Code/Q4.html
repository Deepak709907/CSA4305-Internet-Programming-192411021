Question 4: Database Retrieval

Pseudocode for retrieving data from a database: connect, execute a query, process the result set row by row, and display the retrieved data.

Code

public class Main {

    static String[][] database = {
        {"101", "Laptop", "55000"},
        {"102", "Phone",  "30000"},
        {"103", "Tablet", "25000"}
    };

    public static void main(String[] args) {
        System.out.println("Database Connected");
        System.out.println("Executing SELECT Query...\n");

        System.out.println("ID\tProduct\tPrice");

        for (String[] row : database) {
            System.out.println(
                row[0] + "\t" +
                row[1] + "\t" +
                row[2]
            );
        }

        System.out.println("\nData Retrieved Successfully");
        System.out.println("Database Connection Closed");
    }
}

Output

Database Connected Executing SELECT Query... ID Product Price 101 Laptop 55000 102 Phone 30000 103 Tablet 25000 Data Retrieved Successfully Database Connection Closed === Code Execution Successful ===
