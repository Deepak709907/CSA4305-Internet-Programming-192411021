Question 3: JSP Request Flow

Pseudocode illustrating the request–response flow in a JSP-based web application: the client request is handled by a Servlet, which fetches data and passes it to the JSP for dynamic content generation.

Code

public class Main {

    static class Database {
        static String getData() {
            return "Welcome to the Student Portal";
        }
    }

    static class Servlet {
        static String processRequest() {
            System.out.println("Servlet processing request...");
            return Database.getData();
        }
    }

    static class JSP {
        static void generateResponse(String data) {
            System.out.println("JSP generating dynamic content...");
            System.out.println("Response: " + data);
        }
    }

    public static void main(String[] args) {
        System.out.println("Client sends JSP request");
        String data = Servlet.processRequest();
        JSP.generateResponse(data);
        System.out.println("Response sent to Client");
    }
}

Output

Client sends JSP request Servlet processing request... JSP generating dynamic content... Response: Welcome to the Student Portal Response sent to Client === Code Execution Successful ===
